# Veil Media Studio 1.0.0

Complete Web / Three.js application with source, editable model library, textures, presets, motion data and controller support. Includes PNG export and saved camera shots.

Download Veil-Media-Studio.zip, extract it, and run `node preview.cjs` with Node.js 22 or later. Open http://127.0.0.1:5186. The release ZIP contains real assets and the compiled preview; it does not require Git LFS or npm installation to preview.

All 792 assets and 229 model-attribution mappings were verified. The build and 36 automated input/media checks pass. Existing art issues remain, and visual/physical-controller verification is pending.

Model attribution is preserved in ATTRIBUTIONS.md and ATTRIBUTIONS.json. Keep these and the included license notices with the package.
